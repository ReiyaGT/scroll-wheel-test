How to Test

  1. Place your cursor anywhere on the webpage.
  2. Scroll continuously in a single direction (e.g. fast Downwards).
  3. Observe the plot color. Smooth scrolling produces a single color (Down or Up).
  4. If bright Red / Orange spikes appear during continuous single-direction scrolling, your mouse encoder is registering hardware glitches.

Cara Kerja Web Ini (How This Tool Works)

1. Streamer / Waterfall Visualization

Aplikasi ini menangkap event JavaScript modern WheelEvent secara real-time. Setiap kali mouse mengirimkan input scroll, kanvas menggambar garis vertikal yang merepresentasikan besaran perubahan gerak (deltaY). Posisi horizontal bergeser ke kanan untuk setiap step, menciptakan grafik continuous "waterfall/oscilloscope".

2. Hardware Anomaly & Glitch Detection

Mouse encoder yang rusak/aus sering mengalami masalah encoder bounce atau chatter, di mana scroll ke bawah secara tiba-tiba mengirimkan 1 pulsa sinyal scroll ke atas. Sistem mendeteksi hal ini dengan melacak tren arah scroll terakhir dalam rentang waktu singkat (misal: 180ms). Jika ada sinyal berlawanan yang muncul secara mendadak saat scroll cepat, event tersebut ditandai sebagai Glitch (Warna Merah Vivid).
